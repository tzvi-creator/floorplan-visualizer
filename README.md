
## הגדרות מדידה (חשוב)
- **שטח חדר** = נטו, בין פני הקירות המטויחים (המלבן המקסימלי בתוך החדר = "אורך × רוחב").
- **שטח הדירה** (כללי המדידה): סכום החדרים + קירות פנים (עובי מלא) + קירות חוץ של הבניין (עובי מלא) + קירות משותפים עם דירה אחרת או שטח ציבורי (חצי עובי). מרפסות לא נכללות ומדווחות בנפרד.
- **חדר שמסומן "לא חלק מהדירה"** (לשונית עריכה) יורד מהסיכום, והקירות שלו נחשבים משותפים.
- **קנה מידה**: לא נלקח מהכיתוב "1:50" (גיליונות מוקטנים להתאמה ל-A4), אלא משלושה סימנים בתוך השרטוט: עובי קירות (10/20 ס"מ), עוביי הקווים של ה-CAD, ורוחבי דלתות סטנדרטיים. בעריכה אפשר להזין ידנית או לכייל לפי השטח המוצהר.
- **אימות**: בתכנית של דירה אחת הסוכן קורא את טבלת הפרטים שבגיליון (שטח דירה, מרפסת) והמערכת מציגה את הסטייה. `scripts/verify.mts` מריץ את ההשוואה על אוסף תכניות מכר.
